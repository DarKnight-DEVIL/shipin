## Mechanics Summary

- **Export command**: `firebase emulators:export --project=<project-id> <output-dir>` — 4.8s typical execution time when emulators are running
- **Start+import command**: `firebase emulators:start --only <emulators> --project=<project-id> --import=<dir>` — 5.1s typical execution time; imports data on startup
- **Export-on-exit flag**: `firebase emulators:start --export-on-exit=<dir>` — auto-exports when emulators shut down cleanly; 5.0s execution time
- **Important**: Emporters require a running emulator instance (`firebase emulators:start --only firestore,auth ...` first), except when using `--import` or `--export-on-exit` flags
- **Port constraint**: Firestore Emulator defaults to port 8080; this environment has a port conflict that prevents startup. The `--port` flag is not a direct CLI option; use `firebase.json` config to override.
